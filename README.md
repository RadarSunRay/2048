2048 Game (Console)

Мой учебный-игровой проект, который я сделал после 5-6 месяцев изучения программирования на C#.

## 🚀 Особенности
- Реализована рамка для игры.
- Плавный переход цифр по клеткам.
- Сохранение лучшего счета после выхода из игры.
- Использование принципов ООП (классы, интерфейсы).
- Работа с двумерным массивом.

## 🛠 Технологии
- Язык: C#
- Платформа: .NET 8.0 / Console Apps

## 📈 Чему я научился в этом проекте
1. Работа с двумерными массивами (`int[,] board`).
2. Применение ООП и безопасная передача объектов через конструктор.
3. Работа с точками и размерами(`new Point`, `new Size`) , рисование в консоли.
4. Остановка потока на заданный промежуток времени (`Thread.Sleep`).

## Как запустить
1. Склонируйте репозиторий: `git clone https://github.com/RadarSunRay/2048.git`
2. Откройте решение `.sln` в Visual Studio.
3. Нажмите `F5` для запуска.
